# Допущения и границы справочника тары

## Задача 1. Масса ёмкости

| Решение | Основание |
| --- | --- |
| **ДОПУЩЕНИЕ. Признак МПО с ТУ** | В тестовой БД и в JSON нет отдельного признака ТУ. До появления этого признака международное вложение (`classification = «Международная»`) повышает лимит мешка ПК/ПО до 32 000 г. Международная классификация сама по себе не подтверждает наличие ТУ. |
| **ДОПУЩЕНИЕ. Тара по умолчанию** | Автоматический подбор сохраняет прежний выбор брезентового мешка. Другой совместимый вид и модель оператор может выбрать в реквизитах открытой ёмкости. |
| **ДОПУЩЕНИЕ. Старые снимки** | Значение массы ниже типового лимита прежней версии сохраняется как ручное ограничение. Ручной лимит может уменьшить справочный максимум, а масса старых вложений и документов сохраняется. Если старый снимок содержит неизвестное название модели, для расчёта используется типовая модель известного вида. |
| **Представление неограниченной массы** | Для группы РПО и группы ПТ значение «не ограничено» из справочника представлено максимальным безопасным целым JSON. В карточке ёмкости оно отображается как «без ограничения». |

Источник моделей, массы тары, лимитов и совместимости вида с группой отправлений — таблицы 1 и 2 файла «Справочники.docx». Масса ёмкости считается брутто с учётом массы тары и вложений, как описано в руководстве «Сервис исходящей почты», стр. 18. Если после извлечения или переноса последнего международного вложения допустимая масса снизится, операция отклоняется, пока масса оставшихся вложений превышает новый лимит.

## Отметки ёмкости

- **ДОПУЩЕНИЕ. 1-й класс.** В справочнике надпись «1-ый класс» зависит от вида вложения ёмкости. В прототипе нет отдельного реквизита для этого вида, поэтому надпись добавляется, когда вид каждого вложенного отправления явно содержит «1 класс», «1-го класса» или эквивалентное написание. Смешанная ёмкость эту надпись не получает.
- **ДОПУЩЕНИЕ. EMS.** Условие «вид вложения EMS» проверяется по группе видов отправлений EMS. Виды «EMS оптимальное», «EMS РТ», «Бизнес курьер» и «Бизнес курьер экспресс» сопоставляются по полному нормализованному названию.
- В XLSX нет признаков «Осторожно», «Терморежим», «Негабаритная», типа SRM и разряда «Правительственное». Их явно указывает оператор; начальное значение выключено. Отметки у `IN261116000010` и `IN261116000011` в демонаборе вымышлены. Флаг «Документы» для ТМЦ в исходных данных отсутствует.
- **ДОПУЩЕНИЕ. Ф.23а.** В макете накладной нет подтверждённой справочником колонки отметок, поэтому отметки отображаются на карточке и ярлыке.

## Вложение и взвешивание

- **ДОПУЩЕНИЕ. Контекст вложения.** Внешняя и вложенная ёмкости должны иметь одинаковый рейс и оба направления. Проверки вида и категории, включая обязательную заказную или страховую ёмкость для вложения простой, следуют таблицам 3–4 справочника. Масса дочерней ёмкости учитывается брутто, а сама она представлена в ф.23а через внешнее место.
- **ДОПУЩЕНИЕ. Демо-весы.** Кнопка «Взвесить» и F6 запрашивают показание мок-адаптера. По умолчанию это расчётное брутто со случайным отклонением ±5 г. Настраиваемая погрешность задаётся в пределах ±1000 г. Предупреждение появляется выше допуска max(2% расчётной массы, 50 г). Оператор может указать фактическую массу вручную. Подключение физического устройства за рамками прототипа. Поле доступно для категорий, указанных в руководстве «Сервис исходящей почты», стр. 31.
- **ДОПУЩЕНИЕ. Автовложение.** При включении опции при закрытии мешка выбирается первый совместимый открытый контейнер. Если таких нет, мешок остаётся самостоятельным местом. По умолчанию опция выключена.
- При перегрузе по стабильному показанию закрытие блокируется. Кнопка «Закрыть и открыть следующую» доступна после устранения перегруза или в сценарии, когда текущая ёмкость допустима, а следующее вложение не помещается.
